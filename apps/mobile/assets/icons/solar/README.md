# Solar icons

Icons by 480 Design (Solar), licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

- Original set: https://github.com/480-Design/Solar-Icon-Set
- Distribution: https://github.com/iconify/icon-sets/blob/master/json/solar.json
- Vendored 2026-10-01: `user-plus-bold`, `user-circle-bold`, `letter-bold`, `key-bold`.
- Changes: fixed 24px SVG dimensions and replaced `currentColor` with a black template fill. The app applies the organization color at rendering time.

These use the Bold style from the same Solar icon family used by Ottermates. Only needed drawings are bundled; no icon font or network lookup is used.
